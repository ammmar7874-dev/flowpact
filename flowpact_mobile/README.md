# FlowPact Mobile (Freelancer App)

## Overview
FlowPact Mobile is the Flutter mobile client for freelancers to manage clients, generate milestone payment links, track real-time Solana Devnet settlement, and export verifiable Income Certificates.

## Architecture & Integration
- State Synchronization: Firebase Cloud Firestore (`contracts` collection).
- Network: Solana Devnet.
- Platform: Android & iOS via Flutter 3.41+.

*Implementation scheduled for Phase 4B.*
